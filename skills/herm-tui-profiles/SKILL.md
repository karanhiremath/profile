# Herm TUI profile colors

Do not invent hex. Use the Nighttide family already generated by herm
`scripts/gen-nighttide-themes.ts` and installed by
`bin/hermes/apply-nighttide-theme`.

## Defaults

| Profile / alias | Theme | Notes |
|---|---|---|
| `cos` / `chief-of-staff` | host map | this MBP violet, mini teal, mbp-13 blue, omarchy amber/green |
| `cosw` / `chief-of-staff-work` | `nighttide-ember` | same profile on mac and tc2 |
| `dreamw` / `hdream` | `nighttide-cyan` | distinct from cosw |
| other | keep existing nighttide-* or `nighttide-personal` | |

Unused accents for a new alias: `nighttide-red`, or a host color not already
claimed by Cos on that machine.

## New profile

1. `agents new <name> --dir personal|work|profile` (YAML lives in the matching repo; profile repo stays tool-only).
2. Add the alias to `PROFILE_ALIASES` and a matcher in `is_*_home` / `profile_class` in `bin/hermes/apply-nighttide-theme`.
3. Set `PROFILE_DEFAULT_THEME[<class>]` to an existing `nighttide-*` key.
4. Optional launcher: thin `bin/hermes/<alias>` that `exec`s `agents up <name>`, plus `myprofile.sh` alias.
5. Default eikon: `apply-nighttide-theme --profile <alias> --eikon <name> --set-default`. Do not invent eikon names; use one already under `~/.hermes/eikons/` or herm builtins (`nous`).
6. Tests in `bin/hermes/test_apply_nighttide_theme.py` for class + default theme.
7. `python3 bin/hermes/test_apply_nighttide_theme.py` then `--dry-run`.

## Override without forking the profile

Same YAML on two hosts is fine. Color is not the profile identity.

```bash
# this run only
bin/hermes/apply-nighttide-theme --profile cosw --theme nighttide-blue

# persist on that home
bin/hermes/apply-nighttide-theme --profile cosw --home ~/.local/share/hermes-agents/chief-of-staff-work \
  --theme nighttide-blue --set-default
```

`--theme` writes `herm/tui.json` `theme` for this run. Next apply remaps unless
`--set-default` wrote `nighttideDefault`. `--force` ignores the pin.

## New Nighttide accent

Only if no existing variant fits:

1. Edit herm `scripts/gen-nighttide-themes.ts` (same Ghostty bg, transparent dark surfaces).
2. `bun scripts/gen-nighttide-themes.ts && bun scripts/gen-theme-manifest.ts`.
3. Add the name to `THEME_VARIANTS` in `apply-nighttide-theme`.
4. Ship herm + profile PRs together.
